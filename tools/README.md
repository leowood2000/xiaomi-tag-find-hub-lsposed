# 原生配置格式研究工具

`native_config_format.py` 是离线纯 Python 工具库，不连接 ADB、不写手机，
也不包含 GMS 的混淆类名、方法名或具体设备目录。它尚不是可直接安装的
原生启用程序，不能代替持久性和升级后的实机验收。

已实现：

- 根据 namespace + NUL + account 计算 Murmur3 x64_128 / Base64 URL 文件名；
  测试向量与 2026-11-06 实机读到的路径独立核对一致。
- 校验共享快照格式 `version=1, reserved=0`；未知格式拒绝处理。
- 仅向元数据 override 区增加一个 boolean，原服务器参数区原字节保留。
- 已有同名 override 拒绝覆盖，重复或歧义 map 拒绝处理。
- 使用自身新增 entry 的原始字节作为撤销凭据，只移除完全匹配的 entry。
  其他元数据、其他开关和并发更新后的参数区保留；目标被别人改写则拒绝
  自动撤销；目标已不存在则保持原样。

运行离线测试：

```powershell
py -3 -m unittest discover -s tools -p test_native_config_format.py -v
```

当前 7 项测试通过。另外在不上传的本地实验快照副本上核对，新库产生的
补丁与已验证使原始 debug getter 变 true 的实验文件逐字节相同，撤销结果
也与原始副本完全相同。测试用合成数据和公开 namespace，仓库不包含
真实数据库、账号、快照或令牌。

后续仍需实现并验证：当前生效 salt/目录的唯一识别、设备原子写入和权限

或第一个匹配项来猜测当前路径。不得把此工具接入定时补写来掩盖配置失效。
